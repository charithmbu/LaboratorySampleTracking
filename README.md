# Laboratory Sample Tracking System

A Java console-based application for tracking laboratory samples.

## Features

- Add laboratory sample
- View all samples
- Search sample by ID
- Update sample status
- Delete sample
- Duplicate sample ID prevention
- Basic exception handling

## Technologies

- Java
- ArrayList
- Object-Oriented Programming
- Exception Handling
